# Caregos

Static Caregos publishing source for `https://caregos.com/`.

The production site is under an editorial and AdSense hold. Public pages remain `noindex`, `robots.txt` blocks crawling, sitemap/RSS discovery is empty, and ad loaders are removed. The public held-preview workflow is manual-only and requires the exact `REFRESH_HELD_PREVIEW` confirmation; running it does not approve indexing, monetization, or publication.

See `docs/HANDOFF.md` for the current evidence, validation, rollback, and resume gate.
